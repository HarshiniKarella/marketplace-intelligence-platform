# Marketplace Intelligence Platform

A production-oriented marketplace analytics and machine learning platform built
using the Olist Brazilian E-Commerce dataset.

The project will integrate relational data modeling, ETL pipelines, data
validation, business analytics, machine learning, REST APIs, dashboards,
containerization, automated testing, CI/CD, and cloud deployment.

## Project Status

Project foundation and business requirements are currently being designed.

## Planned Technology Stack

- Python
- PostgreSQL
- SQL
- FastAPI
- Streamlit
- Docker
- GitHub Actions
- AWS
- pytest
- SHAP

## Repository Structure

- `data/` — local raw data and generated datasets
- `docs/` — business, architecture, and project documentation
- `src/` — production application code
- `tests/` — automated tests
- `scripts/` — operational scripts
- `config/` — non-secret configuration
- `notebooks/` — limited exploratory analysis
- `models/` — locally generated model artifacts
- `artifacts/` — reports, metrics, and visual outputs
